Preterite = one finished action (ayer, anoche, el sábado pasado). Imperfect = habits, descriptions, background, time and age in the past (cuando era niña, siempre).

Irregular preterites: ser/ir → fui, fuiste, fue, fuimos, fuisteis, fueron · tener → tuve · estar → estuve · hacer → hice, hizo · poder → pude · poner → puse · venir → vine · decir → dije. Only 3 irregular imperfects: era, iba, veía.

Preterite yo spelling: -car → qué (busqué), -gar → gué (jugué), -zar → cé (empecé).

Ser = what something is (job, origin, description, time). Estar = feelings and location. Gusta + one thing or a verb, gustan + plural.
